# 0004：本地控制台与可扩展 web 目录

- 日期：2026-11-16
- 状态：采用
- 依据：用户希望从网页选择部署模型、运行仿真/真机评测并查看历史；目录命名明确要求为 web，页面名为控制台

使用 `web/` 保存本地控制后端与无构建前端，当前只实现评测模块，不预建采集或 Harness 功能。
Python 标准库 HTTP 服务调用现有脚本，SQLite 保存历史，避免仅做浏览器内模拟或引入与模型环境耦合的 Web 依赖。
单 worker 串行运行，先支持已有 Pi_05/LIBERO 接线，标准 benchmark 与硬件入口由受信任本地配置登记。
CPU mock 用于测试控制链路，与实际评测结果分开，不能作为任何 VLA 的成功率。

控制台支持服务器 IP 直连：默认监听 IPv4 接口，首页自动建立会话，用户不需要输入访问密钥。
定位为可信内网的单用户服务，保留 Host 校验与修改请求令牌（防跨站请求，不是登录权限）；
可用 `--host 127.0.0.1` 限制为回环并通过 SSH 转发。
当前不提供多用户权限、远程集群调度、独立常驻模型服务管理或数据采集模块。
每次评测自动管理相应模型进程，硬件 profile 则连接预先运行的策略服务。未来常驻部署可在 web 下独立扩展。
LIBERO 一次加载模型后串行评测所选 suite，默认四组/每任务 50 次；扩展 90、smoke、
本地已登记任务集合与官方全量协议分别记录，成绩口径见[评测说明](../reference/evaluation-protocols.md)。
详见 [控制台说明](../../web/README.md)。
