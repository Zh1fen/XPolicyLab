# 0005：RoboLab 命名与根目录启动入口

- 日期：2026-11-16
- 状态：采用
- 依据：用户要求启动方式更简单，并希望项目有独立名称、去除上游的展示元素

产品展示名为 RoboLab，控制台页面仍叫“控制台”。根目录 `./start.sh` 自动定位仓库、选择本地或默认配置，
高级参数继续转给既有 Python 入口。模型依赖不因启动控制台而安装或加载。

根 README 聚焦本项目能力与操作，兼容层的详细标准移至 reference，保留原有锚点。
原宣传图、奖项、机构与负责人不作为本项目展示；源码来源和引用集中在 [UPSTREAM.md](../../UPSTREAM.md)，许可证和原始版权信息保留。

发行包名为 robolab-infra，Python 导入名、checkout 路径、协议标识和 Git 远程继续兼容现有 adapter。
全量改包或仓库托管重命名应另行迁移，避免作为展示名称修改的一部分影响既有模型与工作区。
