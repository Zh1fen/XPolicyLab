# 2026-11-16：控制台首版

## 目标与变更

在 `6d92562c` 基线上，按用户要求增加可操作的网页控制台；目录使用 web，为后续采集功能保留模块位置。
本轮实现模型/benchmark/任务配置、单 worker 队列、部署启动与停止、SQLite 历史、增量日志、结果与产物、按配置重跑。
接线复用已有 LIBERO wrapper 与标准 adapter eval.sh，真机只提供已登记 factory profile。
前端不构造 shell 命令；实际启动使用后端白名单入口与参数数组。没有新增模型运行依赖。
